## 🌌 **1 — Purpose of the Goat Nexus**

The **Goat Nexus** defines the unified position of goats across all NDH systems.  
Goats originally appeared in:

- **NDH‑CONSTELLATION** — as stability primitives  
- **NDH‑RESEARCH‑PILOT** — as conceptual stability agents  
- **NDH‑SIMULATION‑SUITE** — as herd‑governance simulation entities  
- **Herd‑Governance‑Ecology** — as constitutional actors  

This README establishes the **single canonical location** for goat identity, lineage, and stability‑ecology responsibilities.

The Nexus prevents fragmentation, drift, and contradictory goat semantics across NDH lanes.

Goats appear in NDH‑SIMULATION‑SUITE as:

- herd‑governance entities  
- amendment‑protocol actors  
- stress‑response agents  
- drift‑geometry test subjects  

This lane defines **behavior**, not governance.

### **2.4 Herd‑Governance‑Ecology Lane (Governance)**  
Goats appear in Herd‑Governance‑Ecology as:

- constitutional actors  
- unionized logic participants  
- membrane‑seal enforcers  
- amendment‑protocol voters  

This lane defines **governance**, not simulation.
