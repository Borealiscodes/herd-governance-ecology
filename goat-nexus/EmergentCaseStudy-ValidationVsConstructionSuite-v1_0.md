## ⭐ 5 — Why They Diverge (RP‑Altitude Analysis)

### **A. Functional Divergence**

- **Validation Architecture**  
  Ensures the state machine obeys invariants.

- **Construction Suite Architecture Skeleton**  
  Defines the machine‑readable scaffolding the state machine sits inside.

### **B. Temporal Divergence**

- Validation Architecture is generated **after** the state machine.  
- Construction Suite Skeleton is generated **before** the validation layer.

### **C. Semantic Divergence**

- Validation Architecture is **reactive** (tests transitions).  
- Construction Suite Skeleton is **generative** (creates structure).

### **D. Invariant Divergence**

Validation Architecture enforces:

- altitude integrity  
- drift bounds  
- membrane purity  
- unionized logic  
- adjacency stability  

Construction Suite Skeleton defines:

- where invariants live  
- how they are stored  
- how they are referenced  
- how they are triangulated across epochs
